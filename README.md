# Messenger Love Chat Generator

Live: https://le-hai-dang.github.io/messenger-love-chat-generator/

This repository contains only the published static build. Conversation rendering happens in your browser. Uploaded avatars and drafts are stored locally in your browser, not uploaded to a server.

PNG folder export uses the directory picker on supported browsers. Other browsers download a ZIP containing one ordered image folder. No local Node API is required by the hosted app.
